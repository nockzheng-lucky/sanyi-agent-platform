日期：2026-08-28
关联：`docs/handoffs/2026-08-22-context-handoff.md` 待办 5

## 本次完成

1. 新增 `app/mcp/`：
   - `client.py`：MCP 本地代理访问平台 REST 的 httpx 客户端；
   - `server.py`：不依赖官方 SDK 的 MCP stdio JSON-RPC 服务；
   - `registry_gateway.py`：远程 MCP 端点直连 FactorRegistry，避免 HTTP 自调用；
   - `__main__.py`：`python -m app.mcp` / `sanyi-mcp` 命令。
2. 新增远程 MCP 端点 `POST /api/v1/mcp`（`app/api/mcp.py`）：
   - 鉴权沿用 `X-API-Token` / `Authorization: Bearer`；
   - `initialize` 返回 `Mcp-Session-Id`，会话 TTL 1 小时；
   - 当前 POST-only，GET 返回 405（未提供 SSE 流）；
   - 会话按令牌身份绑定，过期/串用返回 JSON-RPC -32001 + HTTP 404。
3. 工具契约：
   - `sanyi_list_factors`：免费列因子；
   - `sanyi_evaluate_factor`：查询因子，月费订阅制不逐次扣费；
   - 工具调用成功返回 `content` + `structuredContent`；平台错误返回 `isError: true`。
4. 文档：
   - 新增 `docs/mcp.md`（远程端点、本地 stdio、客户端配置、安全）；
   - `docs/factors/dimen-gate-signal-skill.md` 域名更新为 `signal.shhghf.com` 并补 MCP 接入；
   - `README.md` 更新当前状态。
5. 测试：新增 `tests/test_mcp.py`，当前 `pytest -q` 24 passed。
