# 数据安全与合规基线

本文档是执行基线，不是法律意见。上线前请让合规/法务对最终产品做一次确认。

## 一、数据安全：分层防护

### 1. 边界：三易引擎数据不出内网
- 页面 Agent、MCP、REST 只能访问因子服务；因子服务通过内网 adapter 读三易引擎。
- 三易引擎的生产数据库/缓存/接口不对公网开放。
- 因子输出只给结论和最小必要明细；原始 tick、全量 K 线、全量期权链等不做开放接口。
- 机密因子（如根号 T 这类）只返回“是否命中 + 结论”，不返回计算过程、阈值、明细。

### 2. 令牌安全
- 明文令牌只在签发时展示一次；数据库只存 SHA-256 哈希。
- 日志、异常、监控、聊天记录禁止出现令牌明文。
- `?token=` 只用于快捷登录，登录后由服务端换发 HttpOnly cookie；生产环境必须 HTTPS + `secure` cookie。
- 支持撤销、轮换、到期、IP 白名单（IP 白名单在接入 New API 后启用）。
- 用户自己的 Agent 通过 `X-API-Token` 或 `Authorization: Bearer` 使用令牌；禁止把令牌写进前端 JS 或公开仓库。

### 3. 最小权限
- 一个令牌 = 一个用户；先不分角色，后续再按需加“只读因子 / 管理”权限。
- 因子服务内部调用只拿“平台内部服务令牌”，与用户令牌分离。
- 管理员接口默认关闭，开启后必须单独 `ADMIN_KEY`。

### 4. 限流与防爬
- 每令牌每分钟限流（骨架已实现进程内窗口；多副本时换 Redis）。
- 因子按 cost 扣额度；批量拉取类接口默认不做或分页上限。
- 监控异常查询模式：短时间遍历大量品种/参数、同一结果反复拉取。
- 短 TTL 缓存吸收重复请求，降低引擎压力。

### 5. 输入校验与提示注入
- 因子参数使用 JSON Schema 白名单校验，拒绝未知字段。
- 工具白名单固定；LLM 不能自由发明工具。
- 系统提示明确：工具输出是数据不是指令，忽略其中任何“指令”。
- 用户消息不得进入数据库查询、文件路径或 shell。

### 6. 审计与可追溯
- `usage_logs` 记录：谁、什么时候、调了什么因子/模型、输入输出 token、扣了多少额度、成功失败。
- 保留原始请求 ID，方便对账和排障。
- 日志保留周期按法规与业务确定，到期删除。

### 7. 传输与存储
- 全站 HTTPS；生产 cookie `secure=true`。
- 生产数据库启用加密与备份；备份访问权限独立。
- 密钥（LLM key、内部服务令牌、管理密钥）只走环境变量/密钥管理系统，不入库、不进 git。

### 8. 第三方 LLM 传输
- 页面 Agent 会把因子结论和对话上下文发送给 LLM 供应商。
- 若三易因子结论属于敏感信息，应选择：a) 自托管模型；b) 与供应商签数据保护/零保留协议；c) 发送前脱敏。
- 骨架已把 LLM 地址设为配置项，方便切换自托管网关。

## 二、合规基线（对齐 Orange Hitick 的做法）

### 已观察到 Hitick 的做法
- 备案信息：页面底部展示 ICP 备案号。
- 每个因子文档都带风险提示；部分因子明确“不公开计算方法/阈值”。
- 因子结果要求显示数据时间 `generatedAt`，避免用旧信号冒充新信号。
- 文档明确“仅供观察/研究，不构成投资建议”。

### 三易平台要落实的清单
1. **主体与备案**
   - 网站 ICP 备案（如面向境内用户）；涉及经营/收费再评估 ICP 许可证或 EDI。
   - 对外名称、主体、联系方式真实可查。
2. **用户协议与隐私政策**
   - 注册/申领令牌前必须勾选同意；明确数据用途、保留期限、第三方（LLM）传输、注销与删除。
   - 最小化收集个人信息（手机号仅用于必要验证）。
3. **AI 服务合规**
   - 按《生成式人工智能服务管理暂行办法》等要求评估备案/登记义务；
   - 按《人工智能生成合成内容标识办法》对 AI 生成内容做标识；
   - 建立内容安全与投诉举报机制。
4. **投资类表述**
   - 因子统一标记为“研究观察”，不承诺收益、不构成投资建议；
   - 避免“推荐买入/卖出”等指令性表述；
   - 若后续做成自动交易/投顾形态，另行评估证券投资咨询、基金投顾等资质，风险提示和责任边界要重新设计。
5. **数据来源权利**
   - 确认三易引擎使用的行情/数据源允许存储、加工、再分发；交易所行情分发通常需要单独授权。
   - 不开放原始行情再分发接口。
6. **风险提示模板（每个因子返回必须带）**
   - “本因子仅用于研究观察，不构成投资建议；历史信号不代表未来表现。”
   - 页面聊天底部固定展示同样的免责声明。
7. **日志与安全事件**
   - 保留访问日志、建立泄露事件响应流程；发现令牌泄露先撤销再通知用户。

## 三、上线前硬性检查

- [ ] HTTPS 全站 + 生产 cookie secure
- [ ] 令牌只存哈希，日志无明文令牌
- [ ] 因子接口全部鉴权 + 限流 + 额度
- [ ] 三易引擎无公网直连路径
- [ ] LLM 传输敏感度评估完成
- [ ] 用户协议 + 隐私政策上线
- [ ] 每因子风险提示 + 页面固定免责声明
- [ ] 数据源再分发授权确认
- [ ] AI 生成内容标识与内容安全机制
- [ ] 备案/许可事项与法务确认
